Glossary

Term Definition
Artificial Intelligence The broad field of computer science focused on building systems that simulate human-like reasoning, learning, and decision-making.
Machine Learning A subset of AI where systems learn patterns from data to make decisions or predictions without being explicitly programmed.
Unsupervised ML A type of ML where a model finds hidden patterns or groupings in unlabelled data.
Supervised ML A type of ML where a model is trained on labelled data, learning to map inputs to known outputs.
Engines A computational system or framework that executes a model or algorithm to process data and produce outputs.
Model A mathematical representation learned from data that captures patterns and can be used to make predictions or decisions on new inputs.
Learning The process by which an algorithm iteratively adjusts its internal parameters based on data to improve its performance on a task.
Predicting The application of a trained model to new, unseen data to produce an estimated output.
Principal Components Analysis A dimensionality reduction technique that transforms data into a smaller set of uncorrelated variables that capture the most variance.
Multidimensional Scaling A technique that visualises the similarity or dissimilarity between data points by mapping them into a lower-dimensional space.
Tree-based Clustering A hierarchical clustering approach that organises data into a tree structure, grouping similar observations at successive levels.
K-means Clustering An unsupervised clustering algorithm that partitions observations into k groups by iteratively assigning each point to its nearest centroid and updating centroids until they stabilise.
Hierarchical Clustering An unsupervised clustering approach that builds a dendrogram by repeatedly merging the two closest samples or clusters, without requiring the number of clusters to be fixed in advance.
Train/Test Split Dividing a dataset into a training set (used to fit a model) and a held-out test set (used to evaluate performance on unseen data).
Confusion Matrix A table comparing predicted class labels against true labels, with diagonal cells showing correct predictions and off-diagonal cells showing misclassifications.
AUROC / AUPRC Area Under the ROC Curve / Area Under the Precision-Recall Curve — summary metrics of classification performance across all thresholds; AUPRC is more sensitive to class imbalance than AUROC.
Recipe (tidymodels) A tidymodels object that specifies the preprocessing steps (e.g. normalisation, dummy encoding) applied to data before a model is fit.
Workflow (tidymodels) A tidymodels object that bundles a preprocessing recipe and a model specification together so they are applied consistently during fitting and prediction.
Silhouette Score A per-observation metric ranging from -1 to +1 that measures how similar an observation is to its own cluster compared to the nearest neighbouring cluster; higher values indicate better-separated clusters.
Dendrogram A tree diagram produced by hierarchical clustering that records the order in which samples or clusters are merged, allowing the number of clusters to be chosen by cutting the tree at a given height.
Hyperparameter A model setting (e.g. mtry, k) chosen before training that controls how a model learns, as distinct from parameters estimated from the data itself.
Cross-validation A resampling technique that repeatedly splits data into folds, training on some and evaluating on the rest, to obtain a more robust estimate of model performance than a single split.
Random Forest An ensemble of many decision trees, each trained on a random bootstrap sample of the data and a random subset of predictors at each split; averaging their predictions reduces overfitting relative to a single tree.

Tidymodels vs. Tidyclust

Several tidymodels functions have tidyclust equivalents that are written differently; these should be used when working with clustering workflows:

tidymodels Function tidyclust Equivalent Same
tune_grid() tune_cluster() ❌
finalise_workflow() finalise_workflow_tidyclust() ❌
metric_set() cluster_metric_set() ❌
collect_metrics() collect_metrics() ✅
select_best() select_best() ✅
fit() fit() ✅
predict() predict() ✅

Tidymodels

package step functions
rsample 1. split into test and train sets initial_split(), training(), testing()
recipes 2. create recipe and assign variable rols recipe(), update_role()
parsnip 3. specify model, engine and mode e.g., set_engine(), set_mode(), rand_forest()
workflows 4. create workflow, add recipe, add model workflow(), add_recipe(), add_model()
parsnip 5. fit workflow fit()
parsnip 6. get predictions predict()
yardstick 7. use predictions to get performance metrics rmse(), accuracy(), metrics()
